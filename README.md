# Awesome iPhone Duo

A list of things worth reading and running if you are writing apps for the iPhone Duo's two screens.

It starts small and honest: one entry, my own. The Duo is new and most of what exists right now is speculation rather than code. Entries get added as they prove themselves — if you have built something, open a PR.

- [Contributing](#contributing)

## Sample code

- **[Hello Duo](hello-duo/)** — Hello World for the Duo. One SwiftUI app, two layouts, and the width threshold that tells folded from open. Lives in this repo; clone and run it.

## Contributing

One entry per pull request. Say what it is in a sentence, link something that runs, and note the license if it is code. Anything that is only an announcement, a rumour, or a render of a phone does not belong here.
